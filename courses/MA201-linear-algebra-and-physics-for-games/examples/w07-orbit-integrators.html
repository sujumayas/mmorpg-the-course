Explicit Euler spirals out

Same planet, same gravity, same step size. The only difference is the order of two lines of code. Explicit Euler moves along the old velocity, which is tangent to the orbit, so every step lands a little outside it and the energy climbs. Semi-implicit Euler's errors alternate and cancel, so its orbit stays closed.

Model: GM = 1, a(x) = −x / |x|³, start x = (1, 0), v = (0, v₀), float64 arithmetic. Explicit Euler updates x with the old v, then v. Semi-implicit Euler updates v first, then x with the new v (the order Box2D 3.1 uses). Velocity Verlet moves x with v·dt + ½·a·dt², then averages the old and new acceleration for v. A body closer than 0.05 to the center stops and is marked as crashed. The dashed curve is the exact orbit for this v₀.
