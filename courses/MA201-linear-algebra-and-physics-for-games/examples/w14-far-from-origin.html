Far from the origin, the walk freezes

A float32's spacing doubles every time the distance from the origin doubles. A fixed step per tick gets rounded to a whole number of gaps, so the speed becomes a staircase of wrong values and then drops to zero. A double, or a shifted origin, stays smooth.

Float32 arithmetic uses Math.fround on every stored value: x = fround(x + fround(v·dt)). Float64 uses plain JavaScript numbers. Int32 millimetres adds round(v·dt × 1000) to an integer and stops past 2³¹ − 1 mm. gap32(x) = 2^(floor(log2|x|) − 23), gap64(x) = 2^(floor(log2|x|) − 52).
