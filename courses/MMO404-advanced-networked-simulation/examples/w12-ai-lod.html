Tier policy

A monster is in a tier when its nearest player is closer than the tier radius (strict d < r). Each radius stays above the one before it.

Invented constants. The 20 µs think cost and the 250 ms/s AI budget (a quarter of one core) are the lecture's planning numbers, not measurements from any game.

Positions use the same generator as the lecture's Python (Mersenne Twister, seed 12, monsters first, then players), so the counts match the lecture's simulated rows exactly: 939 / 5,000 / 4,001 for 200 spread players. Tiers use a uniform grid with cells at least 400 m wide to find each monster's nearest player. Context: Gravot, Yokoyama and Miyake, and Emerson, in Game AI Pro (2013); Minecraft Java Edition 1.18 simulation distance.
