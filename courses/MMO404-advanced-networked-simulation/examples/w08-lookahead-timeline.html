How far can two servers drift apart?

Model from MMO404 week 8, section 2. F_A(k) = max(F_A(k−1), F_B(k−L) + δ) + X_A(k), and the same for B, with F(k) = 0 for k ≤ 0 and the second term dropped when k − L < 1. Effective tick = max(F_A(N), F_B(N)) / N, with N = 100 for fixed patterns and 10,000 for random. Random ticks use the lecture's mulberry32 generator, A's 10,000 draws first, then B's. The 40/60 pattern and the 30 to 70 ms range are invented teaching values.
