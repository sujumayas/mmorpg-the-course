MMO301 Virtual Worlds · Week 6 · Worked example

High security space does not forbid a gank. It sets a price on it.

Each bar is the cargo value a hauler can carry before a suicide gank pays for its lost ships. The same hauler with the same cargo is safe in 1.0 space and a profitable target in 0.5 space. The only thing that changed is how fast the police arrive.
