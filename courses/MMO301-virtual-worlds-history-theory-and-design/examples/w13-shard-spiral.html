All parameters are invented for teaching. No real game's numbers are used. Model, monthly: S_t = S_start before the merge and S_after from month m; d = N/S; churn c = c0 + c1·H/(H + d); N(t+1) = N·(1 − c) + A; break-even N_be = (F + k·S)/p. Resting N* solves N·c(N/S) = A by bisection on [0, 10,000,000].
