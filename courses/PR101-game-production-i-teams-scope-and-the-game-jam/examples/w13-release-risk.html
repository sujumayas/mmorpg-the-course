Small risks multiply

A 3% chance that one item breaks looks safe. Twenty such items ship a clean build only about half the time. Checking every item, even with a quick check, beats checking half of them carefully.

Model: items fail independently. checked = round(N × v). P(clean) = (1 − p(1 − c))checked × (1 − p)N − checked. Expected escapes = checked × p(1 − c) + unchecked × p. The grid draws each item with a seeded generator (mulberry32, seed 13), so the first screen is the same on every load. The model value is the one to copy; the sample shows how much 100 releases wobble around it.
