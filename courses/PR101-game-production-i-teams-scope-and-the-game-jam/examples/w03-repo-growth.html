PR101 Game Production I · Week 3 · Worked example

Git keeps every save of every binary, and every clone downloads them all

Without LFS, a new teammate’s first clone grows with every save of every art and audio file. With LFS the clone only fetches the current files. The server still stores every version, so the storage bill does not go away.
