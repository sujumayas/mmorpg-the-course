# Definition of done (template, replace with your team's)

A task moves to Done only when every box is true.

- [ ] Every acceptance sentence on the card is true in a build, checked by someone other than the author
- [ ] The change is merged to main and main still builds with no new errors or warnings in the console
- [ ] The game starts from the title screen and reaches the changed feature without editor-only shortcuts
- [ ] New assets are in the repository (tracked by LFS if they are binary) with their source or license noted
- [ ] No debug keys, test logs or placeholder text that a player could see
