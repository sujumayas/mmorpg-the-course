Same odds, different games

Two dice and a 36-card deck built with the same odds. Draw by draw you cannot tell them apart. Count a player's good turns over a whole game and the deck squeezes the luck out.

Game s uses mulberry32(s), once for the dice and once for the deck.

Model from the week 6 lecture. Dice roll two d6 per turn. The deck holds one card per way to roll each sum, is shuffled with Fisher-Yates and reshuffles when h cards remain. Games are seeded 1 to G with mulberry32, so every number here is reproducible. The deck follows the Catan Event Cards variant (Traders & Barbarians rulebook, 2025 printing). The cards per sum are this course's model, since the rulebook does not list them. No game art is used.
