Swap test

Each row removes one active mechanic alone and recomputes support. Bold cells changed. Critical means some pillar drops to 0. Structural means some pillar at 2 or more drops to 1.

Pillar-mechanic grid

Rows are mechanics, columns are pillars. Arrow keys move between cells, Space toggles a link. Load is the row total. Support counts active rows only.

Model from the lecture: support(p) = Σm active(m) × L[m, p], load(m) = Σp L[m, p]. Swap test for mechanic k: supportk(p) = support(p) − L[k, p]. Critical if any supportk(p) = 0 where support(p) ≥ 1, else structural if any supportk(p) = 1 where support(p) ≥ 2, else safe.
