How many units fit in the frame?

Checking every pair costs n(n − 1)/2 checks, so the naive curve bends upward and hits the budget at 566 units. A 10× faster machine only moves that to 1,789. A uniform grid moves it to 6,921, until the units crowd together.

Model from the lecture: pairs(n) = n(n − 1)/2; T_naive = pairs × c_pair; grid: C = 10,000 cells, c_unit = 1 µs, spread checks = 4.5 n²/C, clustered checks = 0.6 × pairs (the lab's measured ratio); T_grid = n × c_unit + checks × c_pair. n_max values are exact integer searches. Uniform grid after Robert Nystrom, Game Programming Patterns, "Spatial Partition".
