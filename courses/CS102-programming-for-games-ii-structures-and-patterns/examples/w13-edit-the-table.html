      The validating loader follows load_weapons from the lecture: strict integer and float parsing, type in {sword, axe, mace, knife}, 0 ≤ min ≤ max, attacks_per_sec > 0, first row wins on a duplicate id, and upgrade references checked after every row is read. Line numbers are row index + 2, as enumerate(csv.DictReader(f), start=2) counts them. The naive loader uses JavaScript's parseInt and parseFloat, which read 4O as 4 without complaint, and lets a later duplicate row overwrite the earlier one.
