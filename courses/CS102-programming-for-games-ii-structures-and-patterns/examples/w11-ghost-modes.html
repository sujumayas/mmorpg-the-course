An energizer stops the clock

Ghost modes in the arcade Pac-Man (level 1) are a schedule plus a transition table. Eat an energizer and the schedule pauses, so every later switch slides right by exactly F seconds. Leaving frightened never reverses the ghosts.

Reversing edges: chase↔scatter, chase→frightened, scatter→frightened. The two returns from frightened do not reverse.

Model: the ghost-mode rules traced in CS101 week 11 and revisited in CS102 week 11's cross-game section, with the reversal rule stored as a set of (from, to) edges, run at 60 updates per second for 6,000 ticks. Schedule (level 1): scatter 7, chase 20, scatter 7, chase 20, scatter 5, chase 20, scatter 5, then chase forever. While frightened, the phase timer does not count down. An energizer while frightened restarts the fright timer and logs nothing. Times in the log are rounded to 0.1 s. Ghosts are not drawn; this page shows only the timing.
