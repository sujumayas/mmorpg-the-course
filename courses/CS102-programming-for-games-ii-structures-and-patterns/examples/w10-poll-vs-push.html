Model from the lecture: polling costs F × N checks per second; events cost E × L listener calls per second; they cross at E = F × N / L. Event arrivals are a Poisson process, k ~ Poisson(E / F) per frame, from a seeded generator (mulberry32, seed 10), so the first screen is the same on every load. Above 50 events per frame the strip uses the normal approximation.
