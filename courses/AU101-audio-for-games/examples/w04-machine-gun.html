Twelve files, two ways to spend them

Twelve whole gunshots repeat 0.75 times in a 10-shot burst. The same twelve files split into three layers of four repeat 0.14 times. A no-repeat rule takes either to zero. Fire a burst, then run the long-run simulation.

Mode

Each file pool rerolls if it would pick the same index twice in a row. Applies to the two variant modes.

Continuous, uniform. Variant modes only.

Pitches share a group when floor(s / width) matches.

8.75 shots per second is 4/35 s apart, Doom's chaingun.

Output
silent
No sound until you press Fire. All shots are synthesised in the page.
Pitch rules: Doom (1993) scales the sample rate by a random step; this page maps its rule to semitones as s = 12 × log2(1 / (2 − (128 + k)/128)). Heretic's rule subtracts two random numbers, so the middle values are more likely. Repeat chance R = Σ p² over outcomes, independent parts multiply, and a no-repeat pool contributes 0 to immediate repeats. Gunshots are noise and sine sweeps rendered in the browser; no recordings are used.
