The lanes are 1,920 logical px long. One simulated wall clock drives both lanes in 1/240 s ticks. A lane runs a frame whenever its own elapsed time reaches another 1/rate, so the 144 Hz lane gets frames at uneven tick counts, as a real 144 Hz screen would against a 240 Hz clock. Each runner is drawn only on its own frames. Faint dots show the last positions where a frame happened.
