One alien per frame

The loop moves exactly one alien each frame, no matter how many are left. With 55 alive a formation step takes 55 frames, so the march crawls at 2.18 px/s. Remove aliens and the same loop makes the survivors race.

Loop structure after Computer Archeology's annotated disassembly of the Space Invaders arcade code (Taito, 1978): one alien moves per mid-screen interrupt, 60 per second, 2 px sideways per step. The disassembly's special step size for the last alien is left out, as in the lecture. Aliens are drawn as plain blocks.
