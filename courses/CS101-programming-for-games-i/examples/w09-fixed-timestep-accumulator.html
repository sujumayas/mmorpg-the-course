One 60 Hz simulation inside any screen

The screen deposits real time into the accumulator every frame. The simulation withdraws it in fixed 1/60 s chunks. Balls B and C reach the same height on every display rate. Ball A, which uses the screen's own dt, does not.

Model, per display frame: ft = min(frame time, 0.25) if the clamp is on; acc += ft; while acc ≥ SIM_DT − 1e-9, run one step and subtract SIM_DT; alpha = acc / SIM_DT. The tiny tolerance absorbs floating-point error so twelve 144 Hz frames give exactly five 60 Hz steps. The display is simulated, so the numbers do not depend on your real monitor. After Glenn Fiedler, "Fix Your Timestep!" (2004).
