Frightened stops the clock

A power pellet interrupts the scatter and chase schedule. The schedule clock pauses while ghosts are frightened, so every later band slides right by the fright time. Each U-turn mark is a reversal. The end of a frightened band has none.

Model after the lecture's Python and Jamey Pittman's The Pac-Man Dossier (level 1 schedule): scatter 7, chase 20, scatter 7, chase 20, scatter 5, chase 20, scatter 5, then chase forever. The simulation steps at dt = 1/60 s with phase_time -= duration, so a switch lands up to one frame after the table value (7.02 s for 7 s); times here are rounded to one decimal.
