Level 256: one dropped bit, 256 loops

The fruit routine stores level_counter + 1 in a byte. At level 256 that sum is 1 0000 0000. The ninth bit falls off, count becomes 0, and a loop that should run at most 7 times runs 256 times.

Level 255

count = 255 → 7 symbols

level_counter + 1 = 1111 1111 fits in 8 bits. Full branch, returns 7.

Level 256

count = 0 → 256 symbols

level_counter + 1 = 1 0000 0000 needs 9 bits. Early branch, loop runs 256 times.

level_counter equals level minus 1
