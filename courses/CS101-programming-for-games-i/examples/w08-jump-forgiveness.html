Coyote time and the jump buffer

The square runs off the ledge at 90 px/s. Jump is pressed 0.08 s after the edge, but the coyote window is still open, so it jumps from mid-air and clears the pit. Drag the red press marker on the timeline, or change the window, the frame rate and the timer unit.

Model: per frame, just_pressed = held and not was_held; since_ground and since_press reset to 0 or grow by dt; jump if since_ground ≤ C and since_press ≤ B, then both timers reset. A press at time p registers on the first frame with k × dt ≥ p. Run speed 90 px/s (MaxRun) and gravity 900 px/s² (Gravity) are from Celeste's published Player.cs (2018); the 300 px/s jump speed is chosen for this picture. The character is a plain square.
