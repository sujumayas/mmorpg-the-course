Headroom must cover the lag

Servers you ask for arrive 8 minutes late. At 90% utilization, 21,500 players end up in the queue.

Ramp presets

Fixed: c = 500 players per server. Warm-pool servers are booted and empty, so they count as ready from minute 0 and are kept on top of the target.

MinuteDemandReady serversBooting serversReady capacityQueue
Model, one step per minute for t = 0 to 59: D(t) = D0 + r × min(t, ramp duration). Start with ⌈D0 / (u × c)⌉ + W ready servers. Each minute, servers due at t join; want = ⌈D(t) / (u × c)⌉ + W; launch want − ready − booting if positive, ready at t + L; queue = max(0, D(t) − ready × c); pay for ready + booting. The lag and capacity figures are planning numbers from the lecture, not measurements of any game.
