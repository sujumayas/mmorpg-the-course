MMO302 MMO Server Architecture · Week 10 · Worked example

Readers pay for L. The server pays for L².

Every post in a channel of L members is copied to the other L − 1. Posts grow with L, so copies grow with L². Splitting the channel cuts both. Parallel workers only shorten the wait for one post.
