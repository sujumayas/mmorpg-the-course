Simulation: mulberry32 PRNG, seed 405 (each "Draw new players" adds 1). Normals by Box-Muller, one pair of uniforms per draw, drawn per player in the order x, u, v, w. x ~ N(20, 8) hours, y = ρxy(x − 20)/8 + √(1 − ρxy²)·u, s = x + b + σe·v + k·σe·y. w is drawn and reserved. Power: n = ((1.96 + 0.8416) / atanh|r|)² + 3. Theory: r(S, X) = 8/√(64 + σe²) and r(S, Y) = ρxy·r(S, X) when k = 0; with k ≠ 0, cov(S, Y) = 8ρxy + kσe and var(S) = 64 + σe²(1 + k²) + 16kσeρxy.
