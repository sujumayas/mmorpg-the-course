# MMO405 Lab 06 starter

Python 3.10 or later, standard library only. From this folder:

```
python agree.py              # agreement report for prior_codes.csv once your functions work
python agree.py mine.csv     # the same for your own codes (same column layout)
python check_lab06.py        # PASS / FAIL / TODO for each function
```

- `excerpts.csv`: 40 invented interview excerpts from former guild members.
- `prior_codes.csv`: a previous team's codes for the same excerpts, two coders (a, b) and two codes.
- `codebook-v1.md`: the codebook that team used. You will revise it.
- `interview-guide-template.md`: the guide you fill in for your own project.

See ../lab06.md for the steps.
