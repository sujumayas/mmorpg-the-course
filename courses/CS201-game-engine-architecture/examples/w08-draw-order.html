CS201 Game Engine Architecture · Week 8 · Worked example

The CPU pays for every material change

Each bar is one draw call, colored by its material. Every time the color changes, the driver has to switch state. Sort the list and the same draws cost a fraction of the time.

Costs per draw and per switch are round classroom values, not measurements of any one GPU driver. Draws get materials and depths from a seeded random generator (mulberry32, seed 7), so the same settings always give the same strip. Hitman GO is named for its one-material art style described in the lecture; nothing here is taken from the game.
