CS201 Game Engine Architecture · Week 3 · Worked example

Out of memory with half the memory free

Total free memory is the wrong number. The same files in the same budget leave one big free run or many useless small ones, depending only on where each lifetime class may live.

Tests the request against the current arena. It does not change the arena.

Use a whole number from 50 to 200.

Model: each file reads into a temporary buffer, decompresses into a permanent asset while the buffer is still live, then frees the buffer. One heap places every block at the lowest address where it fits (first fit). Two ends packs assets down from the top and puts each buffer at address 0. Free runs are the gaps between used blocks, including before the first and after the last.
