Where does Stunned live?

Press Add and Remove Stunned on one entity. The sparse set writes 8 bytes each time. The archetype copies the whole unit, up to 2 × 112 = 224 bytes. The chart below shows the price the sparse set pays back on every join.

Sparse sets

One pool per component type. sparse[entity] gives the slot, dense[slot] gives the entity.

Archetype tables

One table per exact component set. Cell width is proportional to component size.

Per-frame cost: iterate plus toggle

Byte model and measured costs from the week 5 lecture, section 2: sparse-set toggle about 8 bytes (one dense and one sparse entry) plus the component, archetype toggle up to 2S (copy the row out, move the source table's last row into the hole). Default costs 40 ns and 7 ns per toggle and 0.022 ms archetype movement per system are the lecture's typical values from bench_storage.cpp on an Apple M4 Pro, September 2026. Your machine will differ.
