Same staircase, 2,700 times the bytes

The container decides how many elements move when it grows. The element type decides how many bytes each move costs. One missing noexcept turns 24 bytes into the whole payload.

Growth policy
Model: capacity grows to max(grow(c), size + 1) when full, with grow(c) = 2c (libc++, libstdc++) or c + c/2 (Microsoft STL), and every existing element is relocated. A moved element costs its 24-byte object (three pointers). A copied one costs its whole heap payload. The library picks copy or move with std::move_if_noexcept.
