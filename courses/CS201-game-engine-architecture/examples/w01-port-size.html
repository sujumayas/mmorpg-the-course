Port size is the platform layer plus every file that leaks

A leak costs the size of the file it lands in, not the size of the call. Move each leaked file's OS calls into i_system and watch the bar shrink.

Line counts: wc -l *.c *.h in linuxdoom-1.10 (id Software source release, December 1997) and in WinQuake (GPL release, December 1999). Godot figures are source bytes of scene/, servers/, core/, main/, platform/ and drivers/ in the 4.7.2 release. The 40-line wrapper per moved file is a stand-in, not a measured value.
