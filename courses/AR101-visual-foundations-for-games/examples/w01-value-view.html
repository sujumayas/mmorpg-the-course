L* is CIE 1976 lightness computed from sRGB with the WCAG relative-luminance weights (0.2126, 0.7152, 0.0722). The value view converts each L* back to the sRGB gray with the same lightness. The dungeon room, its figures and the four greens in the handheld preset are invented for this page.
