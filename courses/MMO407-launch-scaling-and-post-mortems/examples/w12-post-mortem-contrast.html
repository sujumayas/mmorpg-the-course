The factor everyone mentions is not always the lesson

A pile of troubled post-mortems only counts how often a factor showed up when things went wrong. Add the smooth launches and some of the loudest factors turn out to be everywhere.

—b / nS, smooth with it

—L = fT / fS

Factor (invented set of 20 troubled and 20 smooth launches)

With half counts, fT = (a + 0.5) / (nT + 1) and fS = (b + 0.5) / (nS + 1). It keeps L finite when a count is zero.
