# Lab 04 starter

- `mailbox.py` is the file you edit. It holds the schema, two naive handlers and an `audit` stub.
- `check_lab04.py` injects a failure at every point of each handler, retries once, and checks conservation and exactly-once behaviour. Run it with `python check_lab04.py` (in this repository, from this folder, `../../../../.venv/bin/python check_lab04.py`).

No packages needed beyond the Python standard library (3.11 or later). On the starter code, 8 of 15 checks pass and 7 fail. That is expected.
