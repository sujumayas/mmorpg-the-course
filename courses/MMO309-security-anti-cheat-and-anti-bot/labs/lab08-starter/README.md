# Lab 08 starter

- `make_scores.py` writes `scores.csv` (20,000 synthetic validation accounts, seed 3098). The checker runs it for you if the file is missing.
- `detect.py` is the file you edit.
- `check_lab08.py` tests your functions and your thresholds. Run it with `python check_lab08.py` (in this repository, from this folder, `../../../../.venv/bin/python check_lab08.py`).

All data is synthetic and does not come from any real game or detector.
