# Lab 06 starter

- `make_ledger.py` writes `bots.csv`, a synthetic ban log for 2,000 bot accounts (seed 309). The checker runs it for you if the file is missing. The data is invented and does not come from any real game.
- `farm.py` is the file you edit. Running it as a script prints the farm's numbers once the TODOs are done.
- `check_lab06.py` tests your functions. Run it with `python check_lab06.py` (in this repository, from this folder, `../../../../.venv/bin/python check_lab06.py`).

Standard library only, Python 3.11 or later. On the starter code every check fails. That is expected.
