# Lab 07 starter

- `make_logs.py` writes `intervals.csv`, `hours.csv` and `labels.csv` (150 synthetic accounts, seed 309). The checker runs it for you if the files are missing.
- `features.py` is the file you edit.
- `check_lab07.py` tests your features and your rule. Run it with `python check_lab07.py` (in this repository, from this folder, `../../../../.venv/bin/python check_lab07.py`).

All data is synthetic. It imitates the shapes discussed in the week 7 lecture and does not come from any real game.
