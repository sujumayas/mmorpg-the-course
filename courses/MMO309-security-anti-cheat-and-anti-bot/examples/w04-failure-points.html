Handler logic follows the lecture's Python code (Ana 300, Bo 0, transfer 100, one retry with the same request ID after any failure): a naive handler commits each write alone; a transaction rolls back every uncommitted write on a crash; a keyed handler also records the request ID inside the transaction and answers a known ID without doing anything. Rates: dupes per crash = λ × w, attacker's chance per try p = min(w / J, 1). All numbers are invented teaching values, not measurements from any game.
