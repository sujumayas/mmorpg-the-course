Model: independent kills with the same drop rate p, no pity timer. Wait percentiles use ceil(ln(1 − q) / ln(1 − p)). The simulation samples each player's first-drop kill as floor(ln U / ln(1 − p)) + 1 with a seeded generator, so the same seed gives the same players.
