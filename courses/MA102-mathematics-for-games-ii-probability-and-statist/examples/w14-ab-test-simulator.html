Observed rates—
Pooled p̂ = (kA+kB)/2n—
SE = √(p̂(1−p̂)·2/n)—
z = (kB/n − kA/n)/SE—
p-value = 2(1 − Φ(|z|))—
Verdict at α = 0.05—

Each experiment draws kA ~ Binomial(n, pA) and kB ~ Binomial(n, pB) and runs a two-sided pooled two-proportion z-test. For n ≤ 1,000 the counts are exact sums of n uniform draws. For n above 1,000 they use the normal approximation to the binomial, rounded to the nearest whole count (continuity correction). Φ uses the Abramowitz and Stegun 7.1.26 erf approximation. Seeded runs use mulberry32.

Analytic power uses the unpooled SE at the true rates, power = Φ(d/SE₁ − zα) + Φ(−d/SE₁ − zα). Required n = (zα + 0.8416)² × (pA(1−pA) + pB(1−pB)) / d², rounded up. pB is capped at 99.9% and floored at 0.1%.
