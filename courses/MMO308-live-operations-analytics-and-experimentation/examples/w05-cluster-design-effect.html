You buy precision with servers, not players

When you randomize whole servers, players on the same server move together. A test with 100,000 players per arm can be as precise as one with 2,000. Make the servers bigger and almost nothing changes. Add servers and the smallest detectable effect drops.

The k range widens when clusters are small. It goes up to 5,000 when m ≤ 20, and up to 100,000 for single players (m = 1).

Formulas as in the lecture: n = k·m, deff = 1 + (m − 1)ρ, n_eff = n/deff, MDE = (1.96 + 0.8416)·√(2p(1 − p)/n_eff). Since n_eff = k·m/(1 + (m − 1)ρ) < k/ρ, a cluster test can never have more effective players than k/ρ, however large each cluster grows (Donner and Klar, cluster randomization trials). All numbers are illustrative, not measured from a real game.
