Model from the week 8 lecture, section 1 and 2: dumb delay = input wait + RTT/2 + server tick wait + snapshot wait + RTT/2 + frame wait; predicted delay = input wait + frame wait. The simulation follows labs/lab09-starter/netsim.py without the snare: 60 Hz ticks, inputs sent every tick with one-way delay RTT/2, the server runs an input on its first tick after arrival, snapshots every 60 / rate ticks, and the client handles a snapshot on its first tick after arrival. The key is sampled on a tick, so measured delays have no input wait.
