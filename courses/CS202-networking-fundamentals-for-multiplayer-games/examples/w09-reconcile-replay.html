Reconcile: start from the server, re-walk the rest

Each snapshot says where the server had you after input a. The client drops the inputs up to a, accepts the server's state and replays the inputs the server has not seen. The run is the lab's simulator, netsim.py, at a 150 ms round trip.

The loop section 2 model

  1. drop every pending input with seq ≤ a
  2. state = S (the server's state)
  3. for each remaining input: state = step(state, seq, move)
  4. correction = state − predicted state before the snapshot

Model: a line-for-line port of labs/lab09-starter/netsim.py with a correct client. 60 Hz inputs, 20 Hz snapshots, 6 m/s (0.1 m per input), one-way delay half the round trip, a scripted walk right for 2 s. The snare is server-side: 60 inputs at half speed from 1.0 s of server time. Smoothing fades the display offset linearly, as Source's cl_smoothtime does (Source SDK 2013).
