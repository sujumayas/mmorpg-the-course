Client upload r (i + h). Server upload n r (n s + h). Listen host upload (n − 1) r (n s + h). Relay: each peer r (s + h), relay n (n − 1) r (s + h). kbit/s = B/s × 8 / 1000. Latency through a hop is the sum of the two legs.
