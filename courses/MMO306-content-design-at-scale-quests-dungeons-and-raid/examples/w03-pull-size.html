How big should a pull be?

Under the target cap, area damage hits every enemy at once, so ten enemies die as fast as one. A bigger pull is free time, right up until the tank's health runs out before the pack's does.

Target cap m
1.00 (L0)1.47 (L5)2.16 (L10)
Advanced: fixed values
—tkill, pack dies
—tsurv, tank lasts
—pulls needed, M / N
—seconds per pull, kill + walk
—clear time (min)
—enemy forces per second, walking included
—largest safe pull (fastest clear)
—clear time at that pull

tkill = H / A if N ≤ m, else H × N / (A × m)  ·  tsurv = B / (N × d − Q)  ·  clear = (M / N) × (tkill + w) / 60

All numbers are invented for teaching, as in the lecture. The scaling ticks use World of Warcraft Mythic+'s 8% per keystone level for enemy health and damage (Warcraft Wiki, "Mythic+", The War Within): 1.085 ≈ 1.47 and 1.0810 ≈ 2.16.
