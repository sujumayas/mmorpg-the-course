Blob or rows?

A blob is cheap to load whole and expensive to change in part or search across. Rows are the reverse. Drag inventory size I and watch “move one item”: the blob cost climbs in a straight line, the row cost stays flat.

Operation
–item rows, C × I
–rows per page, ⌊8168 / r⌋
–pages
–row table, pages × 8,192
–blob table, C × I × j

Copies the 40-byte item name into every row: r goes from 60 to 100 bytes, and renaming a type must touch every copy.

Model from DB201 week 2. Row size r = 60 bytes is a PostgreSQL row (28 bytes of data, 24-byte header, padding to 8, 4-byte line pointer); pages are 8,192 bytes with 8,168 usable. The blob size is before compression. 1 kB = 1,000 bytes. Shapes are generic; no game art.
