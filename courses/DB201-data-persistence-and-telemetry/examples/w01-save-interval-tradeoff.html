DB201 Data Persistence and Telemetry · Week 1 · Worked example

Writes per second × average loss = N / 2

A periodic save policy trades lost progress for database writes. The save interval T cancels out of the product, so every choice of T lands on the same curve.

Move T: the point slides along the curve. It never goes below it.

–writes/s, W = N/T
–write volume, B = N·S/T
–average loss, T/2
–worst loss, T
–player-hours lost per crash
–W × T/2 (always N/2)
–hybrid writes/s
–hybrid write volume
